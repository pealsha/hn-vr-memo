# HnMemo の使い方

SteamVRの空間にノートを出して手書きするWindowsアプリです。VRChatと一緒に使え、PCでも同じメモを編集できます。JSONとPNGへ自動保存します。
作者: ひのえるし(hinoerusi)。名前の Hn は作者の印（hinoe）です。バージョンは `HnMemo.exe` のプロパティ →「詳細」→「製品バージョン」で確認できます。

## 導入・起動

Windows 10/11の64bit PC用です。VRではSteamVRと対応コントローラーが必要です。PC画面だけならSteamVRは不要です。**配布版は.NETを同梱する構成で、別途ランタイムを入れる必要はありません。**

1. zip全体を「すべて展開」し、中の `HnMemo` フォルダを置きます。exeだけ取り出さないでください。
2. **配置先は、パス全体が半角英数字・記号・空白の場所（例: `C:\HnMemo`）にします。** 日本語などが含まれるとSteamVRの自動起動に失敗します。Windowsのユーザー名が日本語なら、デスクトップやドキュメントの下も避けてください。メモの保存先は別です。
3. PCで使うときは `Desktop-HnMemo.cmd`、VRで使うときはSteamVRを起動して `Start-HnMemo.cmd` を開きます。

署名のないアプリなのでSmartScreenが警告する場合があります。入手元を確認し、信頼できる場合だけ「詳細情報」→「実行」を選んでください。「実行」が出なければPCの管理者へ確認してください。Windows全体の保護を無効にする必要はありません。

## VRで書く

1. 何も持たず、利き手と反対の手首の内側を見て、もう一方の指先でトントンと**2回**叩きます。1回目で紫の丸が出ます。1.6秒以内にもう一度触れて離すと、丸にチェックが付いてノートが出ます。同じ操作で隠せます。
2. ノートの横のペンへ手を近づけ、グリップを握って持ちます。ペン先をノートの手前15cm以内に入れ、トリガーで書きます。消しゴムもグリップで持ち、トリガーで消します。
3. ノートの上端の外側で色・太さ・消し方を選びます。「線ごと消す」は一筆全体、「部分消し」は触れた範囲を消します。「元に戻す」「やり直す」で筆跡を戻せます。
4. 「新しいページ」で白紙へ、「一覧」で以前のメモへ移ります。選んだ後はトリガーを一度離してから書き足します。下角の外側の矢印をグリップで持つとノートの大きさを変えられます。

手首タップは、指を入ってきた側へ戻します。0.5秒を超えて触れる・目を離す・物を持つ・グリップを握る・追跡切れ・ダッシュボード中は取り消します。起動や中断の後は指を一度離してください。トリガーの押下だけでは止まりません。

位置が合わなければ、PC右上の歯車（設定）またはSteamVRダッシュボードの **HnMemo** で「手首の位置を合わせる」を押します。ダッシュボードを閉じ、3秒の準備中に反対の手首の叩きたい所へ指先を置き、約2秒止めます。保存の合図が出たら離します。「位置合わせを中止」で中断できます。左右の利き手の位置は別々に保存します。

ノートが見つからない場合は、ダッシュボードの「ノートを出す」や「ノートと道具を正面に戻す」を使います。PCの通知領域（時計付近。隠れていれば「∧」の中）のアイコンからも「正面へ戻す」を選べます。

**グリップ・トリガーの入力はVRChatにも届きます。** アバターやワールドの操作と競合する場合があります。

## SteamVRのボタン割り当て

Quest系・Index・Viveの既定バインドを同梱しています。反応しなければ **HnMemo** の割り当てを確認してください。

| 動作名 | 左右それぞれの割り当て |
|---|---|
| ペン・ノート・消しゴムを持つ / Grab pen / board / eraser | グリップ |
| 書く・消す・選ぶ / Draw / erase / select | トリガー |
| 手の握り姿勢 / Hand grip pose | Grip Pose（`/pose/grip`） |

任意のボタンでノートを出し入れする場合は、SteamVRの「設定」→「コントローラ」→「コントローラのバインドを管理」から **HnMemo** を選びます。「アクティブなコントローラのバインド」を「カスタム」にし、「このバインドを編集」を開きます。好きなボタンの「クリック」に **ノートを出す・隠す / Show / hide board** を割り当て、「個人用バインドを保存」で保存します。版により「現在のバインド」→「編集」が入口になる場合もあります。

この操作は既定では未割り当てです。「ノートの出し方」が「使わない」でも有効です。持つ・書く・握り姿勢の割り当ては残し、VRChatやVirtual Desktopと競合しないボタンを選んでください。

## PCで見る・整理する

`Desktop-HnMemo.cmd` で開き、左の「一覧」でページを選び、右の紙へマウスの左ボタンやペンタブで書きます。道具・色・太さは上で選びます。PCとVRは同じページを共有します。

- 一覧のページを右クリックすると「名前を変更」「複製」「ピン留め／ピン解除」「ゴミ箱へ移動」を選べます。
- 「選択」で複数ページを選び、下のボタンでまとめて整理できます。「完了」またはEscで終了します。Ctrl・Shiftによる選択も使えます。
- ゴミ箱へ移した直後は、一覧のページや余白の右クリック **「移動を元に戻す」** で戻せます。左の一覧列にフォーカスがある時のCtrl+Zも同じ操作です。紙・描画ツールにフォーカスがある時のCtrl+Zは筆跡を戻します。
- 「ゴミ箱」の「復元する」で戻せます。「完全に削除」とゴミ箱を空にする操作は、確認後に元へ戻せない削除を行います。

ウィンドウを閉じると保存して通知領域へ戻ります。アプリ全体を終えるときは通知領域アイコンの右クリック→「終了」です。SteamVRを閉じてもアプリは終了しません。

## 設定・保存先

PC画面右上の歯車（設定）から変更できます。

| 項目 | 内容 |
|---|---|
| ゴミ箱の自動削除 | しない／1日／14日／30日／60日。既定30日。期限を過ぎたページは完全削除され、元へ戻せません |
| SteamVR と一緒に起動 | SteamVRの起動中はその場でオン・オフを変更できます。停止中に選んだ変更は、次にHnMemoとSteamVRが両方起動して接続したときに反映します |
| 利き手・ノートの明るさ | 右利き／左利き、100%／80%／60% |
| 手首タップ・タップ回数 | 使う／使わない、2回タップ／1回タップ。SteamVRでボタンに割り当てた「ノートを出す・隠す」はどちらでも使えます |
| タップ時の振動 | オフ／オン。既定オフ |
| 手首の位置を合わせる | 上の手首タップの位置合わせを開始します |
| 保存先を開く・保存先を変更… | フォルダを選び「移して変更／移さず変更／キャンセル」を選びます。移す場合はゴミ箱・バックアップも含めて確認してから元を削除し、衝突や途中失敗では元を残します |

アプリのフォルダを移した場合は、下の「更新」の手順で自動起動を登録し直してください。移動前に解除する必要はありません。画面を使えない場合の登録・解除用に `Enable-Autostart.cmd` と `Disable-Autostart.cmd` も同梱しています。

メモは既定でWindowsの「ドキュメント」内の `HandwriteMemo` に保存します。「保存先を開く」で実際の場所を確認できます。ドキュメントの移動や設定により場所は異なります。再起動時は白紙から始まり、以前のメモは「一覧」から開けます。

設定は `%LOCALAPPDATA%\HandwriteMemo\settings.json`、ログは `%LOCALAPPDATA%\HandwriteMemo\logs`、終了時の復旧コピーは `%LOCALAPPDATA%\HandwriteMemo\Recovery` です。`%LOCALAPPDATA%` はWindowsがユーザーごとに用意する場所で、エクスプローラーのアドレス欄に入力して開けます。細かい位置調整は `settings.example.json` を参考に必要な項目だけ編集し、再起動してください。

## 更新・削除

**更新:** 通知領域から「終了」→新しいzip全体を別の一時フォルダへ展開→元のアプリフォルダの中身を新しい中身と入れ替え→同じ場所から起動します。メモと個人設定は別の場所なので残ります。

新しいフォルダへ入れ替えた場合やフォルダを移動した場合、自動起動を使うにはSteamVRを起動し、新しい場所の `Enable-Autostart.cmd` を一度実行してください。PCの設定で「SteamVR と一緒に起動」をオンにする方法でも登録できます（既にオンなら一度オフにしてからオン）。古い場所の登録は自動で外して、新しい場所へ登録し直します。古いフォルダが既になくても登録できます。通常起動だけでは登録先は変わりません。

**旧名の版からの更新:** exeは `HnMemo.exe`、起動用cmdは `Start-HnMemo.cmd`・`Desktop-HnMemo.cmd` になりました。古いショートカットは新しいexeまたはcmdへ作り直してください。自動起動を使っていた場合は、上記の方法で新しい場所から登録し直してください。登録エラーの場合はSteamVRが起動していることと配置先を確認し、新しい場所の `Enable-Autostart.cmd` を再実行してください。以後、配置先・exe名が変わらない更新では再登録は不要です。

メモ・設定・ログ・復旧コピーのフォルダ名は互換性のため `HandwriteMemo` のままです。既存のメモも、設定で選んだ保存先も、そのまま読み書きし、移動やコピーは行いません。フォルダを改名する必要はありません。

**削除:** SteamVRを起動して「SteamVR と一緒に起動」をオフ（または `Disable-Autostart.cmd`）→通知領域から「終了」→アプリのフォルダを削除します。解除できない場合はアプリのフォルダを残し、SteamVRの起動と配置先を確認してください。メモと設定・ログは自動では消えません。不要な場合だけ、実際の保存先と `%LOCALAPPDATA%\HandwriteMemo` を、残したい内容をコピーしてから削除してください。

保存エラーでは内容を保持し、ページ移動や通常終了を止めます。保存先の容量・使用状態を直し「保存を再試行」を選んでください。PNGがなくてもJSONは消さないでください。次の起動で再生成できます。起動しない場合は、zipを全体展開したか、DLLがセキュリティソフトなどで隔離されていないかを確認してください。
