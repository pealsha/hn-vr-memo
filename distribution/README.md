# HnMemo の使い方（詳細ガイド）

HnMemo は、SteamVR の空間にノートを出して手書きする Windows アプリです。VRChat と一緒に使え、PC 画面でも同じメモを開いて編集できます。書いた内容は JSON と PNG へ自動保存します。
自分用に作ったので、使いたい方がいれば使ってください。

作者: ひのえるし (hinoerusi)（名前の Hn は作者の印です）。バージョンは `HnMemo.exe` のプロパティ →「詳細」→「製品バージョン」で確認できます。

## 動作環境と注意事項

- Windows 10 または Windows 11 の 64bit PC 用です。VR では SteamVR と対応コントローラーが必要です。PC 画面だけなら SteamVR は不要です。
- **配布版は.NETを同梱する構成で、別途ランタイムを入れる必要はありません。**
- SteamVR・VRChat の非公式ツールです。**グリップ・トリガーの入力は VRChat にも届きます。** アバターやワールドの操作と競合する場合があります。
- 署名のないアプリのため、SmartScreen が警告を出すことがあります。入手元を確認し、信頼できる場合だけ「詳細情報」→「実行」を選んでください。「実行」が出ない場合は PC の管理者へ確認してください。Windows 全体の保護を無効にする必要はありません。

## 導入と初回起動

1. `HnMemo-*-win-x64-setup.exe` を開き、画面に従ってインストールする（`C:\Program Files\HnMemo` に入る）。
2. 完了画面の「HnMemo を起動する」か、スタートメニューの「HnMemo」を選ぶ。PC 画面が開く。
3. SteamVR を起動し、VR 内で SteamVR ダッシュボードを開く。**HnMemo** タブで「ノートを出す」を選び、ダッシュボードを閉じる。
4. ノートの横にあるペンに手を近づけ、グリップを握って持つ。ペン先をノートの手前 15 cm 以内に入れ、トリガーを引いて書く。

手動で起動すると、SteamVR の起動状態にかかわらず PC 画面が開きます。SteamVR を後から起動した場合も、HnMemo は起動したまま接続を試みます。

## VR の操作

### ノートと道具の操作

| やりたいこと | 操作 |
|---|---|
| ペン・消しゴムを持つ | 道具に手を近づけてグリップを握る。その場に置くときはグリップを離す |
| 書く・消す | 道具の先をノートの手前 15 cm 以内に入れ、トリガーを引く。道具の先から紙へ垂直に下ろした位置が操作点 |
| 色・太さ・消し方を変える | ノート上端の外側にあるパレットに道具の先を重ね、トリガーを押す。「線ごと消す」は一筆全体、「部分消し」は触れた範囲を消す |
| 元に戻す・やり直す | ノート上部の左右に曲がった矢印に道具の先を重ね、トリガーを押す |
| ノートを動かす | 空いている手を紙に近づけ、グリップを握ったまま移動する |
| ノートの大きさを変える | 紙を手放し、右下の矢印（左利きなら左下）を空いた手でグリップして引く。道具の先を矢印に重ね、トリガーを引いたまま動かす方法も使える |
| ページを切り替える | 「新しいページ」で白紙を開く。「一覧」ではカードに道具の先を重ねてトリガーを押す |
| ノートと道具を正面に戻す | SteamVR ダッシュボードの **HnMemo** タブで「ノートと道具を正面に戻す」を選ぶ |

ページ切り替えや道具の持ち替えの直後は、トリガーを一度離してから書き始めます。
ノートが見つからない場合は、SteamVR ダッシュボードの **HnMemo** タブで「ノートを出す」または「ノートと道具を正面に戻す」を選んでください。

### 手首タップでノートを出す・隠す

ダッシュボードを開かずにノートを出し入れできます。タップ位置は既定では手首付近です。

1. 何も持たず、利き手と反対の手のタップ位置を見る（右利きなら左手）。
2. 利き手の指先でその位置を軽く叩き、指を離す。1 回目で紫の丸が出る。
3. 1.6 秒以内にもう一度叩いて指を離す。丸にチェックが付いてノートが出る。同じ操作で隠せる。

手首タップの細かい条件は次のとおりです。
- タップ位置に触れたら、指を近づけた側へ戻します。
- 0.5 秒を超えて触れる・タップ位置から目を離す・物を持つ・グリップを握る・追跡が切れる・ダッシュボードを開く、のいずれかで入力は取り消されます。起動直後や中断後は指を一度離してからやり直してください（トリガーの押下だけでは止まりません）。
- タップ回数（2 回／1 回）や有効・無効は、PC 画面の設定またはダッシュボードの **HnMemo** タブから変更できます。

### 手首の位置合わせ

手首や手の甲など、利き手と反対の手のタップしやすい位置を登録できます。

1. SteamVR に接続した状態で、PC の設定または SteamVR ダッシュボードの **HnMemo** タブから「手首の位置を合わせる」を押す。
2. SteamVR のダッシュボードを閉じ、3 秒の準備中に、利き手の指先を反対の手のタップしたい位置に置く。
3. 「測定中」と表示されたら約 2 秒止め、「手首の位置を保存しました」と表示されたら指を離す。

途中でやめる場合は「位置合わせを中止」を押します。右利きと左利きの位置は別々に保存されます。

## SteamVR のボタン割り当て

Quest 系・Index・Vive の既定バインドを同梱しています。反応しない場合は、SteamVR のコントローラー設定で **HnMemo** の割り当てを確認してください。

| 動作名 | 左右それぞれの割り当て |
|---|---|
| ペン・ノート・消しゴムを持つ / Grab pen / board / eraser | グリップ |
| 書く・消す・選ぶ / Draw / erase / select | トリガー |
| 手の握り姿勢 / Hand grip pose | Grip Pose（`/pose/grip`） |

任意のボタンでノートを出し入れしたい場合は、次の手順で割り当てます。

1. SteamVR の「設定」→「コントローラ」→「コントローラのバインドを管理」から **HnMemo** を選ぶ。
2. 「アクティブなコントローラのバインド」を「カスタム」にし、「このバインドを編集」を開く（版により「現在のバインド」→「編集」）。
3. 好きなボタンの「クリック」に **ノートを出す・隠す / Show / hide board** を割り当て、「個人用バインドを保存」で保存する。

この操作は既定では未割り当てです。設定の「手首タップ」が「使わない」でも有効です。持つ・書く・握り姿勢の割り当ては残し、VRChat や Virtual Desktop と競合しないボタンを選んでください。

## PC の操作

左の「一覧」でページを選び、右の紙へマウスの左ボタンやペンタブレットで書きます。道具・色・太さは画面上部で選びます。PC と VR は同じページを共有します。

- **名前の変更・複製・ピン留め・ゴミ箱へ移動**：一覧のページを右クリックして選びます。名前の変更は `F2` でも始められ、`Enter` で確定します。空欄で確定すると作成日時の名前に戻ります。
- **複数ページの整理**：「選択」でページをチェックし、一覧の下にあるボタンでまとめて操作します。「完了」または `Esc` で終了します。`Ctrl`・`Shift` による選択も使えます。
- **ゴミ箱からの復元と完全削除**：ゴミ箱へ移した直後は、一覧の右クリック「移動を元に戻す」で戻せます。「ゴミ箱」タブでは「復元する」「完全に削除」「ゴミ箱を空にする」を使えます。完全削除は確認後に元へ戻せない削除を行います。
- **元に戻す（`Ctrl+Z`）**：紙や描画ツールにフォーカスがあるときは筆跡を、左の一覧列にフォーカスがあるときはゴミ箱への移動を取り消します。

ウィンドウを閉じると保存して通知領域へ戻り、VR ではそのまま使えます。アプリ全体を終了するときは、タスクバーの時計付近にある通知領域のアイコンを右クリックして「終了」を選びます。SteamVR を閉じてもアプリは終了しません。

## 設定と保存先

PC 画面右上の歯車（設定）から変更できます。

| 項目 | 内容 |
|---|---|
| 利き手・ノートの明るさ | 右利き／左利き、100%／80%／60% |
| 手首タップ・タップ回数 | 使う／使わない、2 回タップ／1 回タップ。SteamVR で割り当てた「ノートを出す・隠す」はどちらでも有効 |
| タップ時の振動 | オフ／オン（既定オフ） |
| 手首の位置を合わせる | 上記の手首タップ位置合わせを開始 |
| SteamVR と一緒に起動 | SteamVR 起動中はその場でオン・オフを反映。停止中に選んだ変更は、次に HnMemo と SteamVR が接続したときに反映 |
| 保存先を開く・保存先を変更… | フォルダを選び「移して変更」「移さず変更」「キャンセル」から選択。移す場合はゴミ箱・バックアップも含めてコピーを確認してから元を削除し、衝突や途中失敗では元を残す |
| ゴミ箱の自動削除 | しない／1 日／14 日／30 日／60 日（既定 30 日）。期限を過ぎたページは完全削除され、元へ戻せない |

SteamVR が HnMemo を自動起動したときは、PC 画面を開かずに通知領域に常駐します。スタートメニューの「HnMemo」か `HnMemo.exe` を開くと、常駐中でも PC 画面を表示できます。

### 保存ファイルとバックアップ

既定の保存先は Windows の「ドキュメント」内にある `HandwriteMemo` です。実際の場所は設定の「保存先を開く」で確認できます。書いている間は約 1 秒ごとに保存し、一筆の終わりやページ切り替え時にも保存します。再起動時は白紙から始まり、以前のメモは「一覧」から開けます。

- **JSON**：ページを開いて再編集するためのデータです。PNG がなくても JSON が残っていれば次回起動時に PNG を再生成します。
- **PNG**：同じページの画像ファイルです。
- **`.json.bak`**：JSON 更新前のバックアップです。旧形式から更新したページでは `.json.v1.bak` も残ります。
- **手動バックアップ**：HnMemo を終了してから保存先フォルダ全体（`Trash` を含む）をコピーします。
- **設定・ログ・復旧コピー**：`%LOCALAPPDATA%\HandwriteMemo` の下に `settings.json`、`logs`、`Recovery` があります。エクスプローラーのアドレス欄に `%LOCALAPPDATA%\HandwriteMemo` と入力して開けます。細かい位置調整は `settings.example.json` を参考に必要な項目だけ編集し、再起動してください。

## 更新と削除

### 更新

1. 通知領域のアイコンを右クリックし、「終了」を選ぶ。
2. 新しいインストーラーを実行して上書きインストールする。
3. スタートメニューの「HnMemo」を開く。メモと設定は引き継がれる。

### 削除

1. 通知領域のアイコンを右クリックし、「終了」を選ぶ。
2. Windows の設定の「アプリ」で HnMemo の「アンインストール」を選ぶ（SteamVR の自動起動登録も自動で解除される）。

メモ・設定・ログは削除後も残ります。不要になった場合は、メモの保存先フォルダと `%LOCALAPPDATA%\HandwriteMemo` を削除してください。

## トラブルシューティング

- **保存に失敗する**：筆跡はアプリ内に保持され、ページ移動や通常終了を止めます。保存先の空き容量や他アプリによる使用状態を確認し、PC 画面の「保存を再試行」を押してください。終了時に復旧コピーを保存した通知が出た場合は `%LOCALAPPDATA%\HandwriteMemo\Recovery` を確認してください。
- **起動しない**：DLL がセキュリティソフトに隔離されていないか確認し、必要なら再インストールしてください。ログは `%LOCALAPPDATA%\HandwriteMemo\logs` にあります。
