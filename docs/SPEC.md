# SPEC — VR手書きメモ帳

## 目的(Why)
VRChat をプレイ中、メモを取るのが面倒。Virtual Desktop でメモ帳を開きレーザーでキーを打つのは遅く、
特に数式はキーボード(LaTeX含む)ではほぼ書けない。
QvPen で文字を書き慣れているので、同じ感覚で手書きでき、PC に記録が残るメモ帳が欲しい。

## 利用場面
VRChat で遊んでいる最中に思いついた数式・単語・アイデアを、数秒で書き留めて PC に残す。
後で(VR内/デスクトップで)開き直して書き足し・書き直しができる(iOS のフリーボードのように)。

この文書は現在有効な要件と将来候補を示します。利用手順は[README](../README.md)、
実装構成・検証は[DEVELOPMENT](DEVELOPMENT.md)、判断理由は[ADR](adr/)を参照します。

## 要件
### 起動
- SteamVR と一緒に自動起動し、普段は非表示
- 素早くノートを出す/消す。利き手でない手首の握り姿勢から、手のひらが頭を向く、かつ頭が手首を向くことを判定する。利き手の推定指先が手首周囲の範囲に入り、入ってきた側へ戻る短い動きをタップとする。先にボタンを出さず、1回目で紫の丸、2回目を離すと切り替えと丸へのチェックを出す。0.5秒を超える接触、1.6秒の時間切れ、目を離す、保持中・グリップ押下・追跡不良・ダッシュボード中は中断する。トリガー押下だけでは止めない。PC設定・VRダッシュボードで「手首タップ」の「使う／使わない」「2回タップ（既定）／1回タップ」を選ぶ。PC設定で合図の振動をオン・オフ（既定オフ）にできる。
- 旧保存値 `WristDoubleTap`・`BackOfHand`・`HeadDoubleTap` とモード項目のない設定は手首タップとして読み、`Disabled` と旧 `WristGestureEnabled: false` は無効のままとする。設定の項目名・保存形式は維持する。
- PC設定・VRダッシュボードの「手首の位置を合わせる」から、ダッシュボードを閉じた後3秒の準備と約2秒の静止で中心を取得する。手首側の握り座標で1.5cmを超える動きや追跡中断は再試行、30秒で時間切れ。保存成功・失敗を画面で示し、途中の中止も可能。左右の利き手ごとに中心を保存し、判定は半径5cmの球で、中心から6.5cm離れると次のタップを受け付ける。未設定時は左手首基準(.141,.192,−.023)mを使い、右手首ではXを反転する。
- 開始と中止は別ボタンとし、中止は位置合わせ中だけ表示して入力を受け付ける。測定中に開始を押し直しても継続する。PC設定・ダッシュボード・メニューを閉じた後のVR案内は同じ測定状態を表示する。途中でダッシュボードを開くと、次に閉じるまで待ち、準備から測り直す。待機中は時間切れにならない。
- SteamVR Input に任意の boolean アクション「ノートを出す・隠す」/「Show / hide board」を用意する。既定は未割り当て。「使わない」を含むジェスチャー選択から独立し、未割り当てでも起動・既存入力を妨げない。ダッシュボードの既存操作も維持する
- 通知領域アイコンのメニューは「デスクトップ画面を開く」「保存フォルダを開く」「終了」の3項目（区切り線なし）とする。利き手・VRの明るさ・保存の再試行はPC画面／設定画面へ、ノートの出し入れ・正面戻しはVR側（手首タップ・SteamVR割り当て・ダッシュボード）へ集約する

### 書く・持つ(VRChat のピックアップ/QvPen と同じ操作感)
- ペンとノートは、どちらもグリップで掴んで持つ「物」。左右どちらの手でも掴める
- 掴める判定は「手(握っている位置)が物体から一定範囲内」。物体がどの向き・どこに置かれていても同じように掴める
- 掴める範囲に手が入ったら物体が強調表示される(VRChat のピックアップと同じ)
- 持ち替え: 片手で持っている物を反対の手で掴むと、そちらの手に移る(持ち方の調整に使う)
- ペンを持った状態でトリガーを押している間、線を描く(QvPen と同じ)
- 描く位置はペン先をノートへ垂直に投影した位置。ノートの手前15cm以内なら描ける(Task 003 実機で「ちょうどよい」。設定で変更可)
- ペンの見た目があり、ペン先の位置が一目で分かる(アバターの指の大きさに依存しない)
- 持ち方は自由: ペンは掴んだ時の手との位置関係を保つ(ノートと同じ。決まった持ち方へのスナップはしない)
- ペンを離すとその場に留まる。ノートを出し直すとノートの横(定位置)に戻る
- グリップ・トリガーは VRChat にも届く(抑止できない)。Task 003 実機では特に実害なし(ADR 0003)

### 操作(最小)
- 元に戻す / 新しいページ / 閉じる(保存は自動。ADR 0004)

### 保存
- 線を「ストロークデータ」(点列・時刻などを持つ編集可能な形式)で保存する  ← 後で書き直すための必須要件
- 同時に見返し用の PNG も書き出す
- 保存先フォルダは設定可能(既定は ドキュメント\HandwriteMemo)、ファイル名は日時
- 保存は自動: 書いたメモは消えない。ノートを閉じた時・新しいページにした時・アプリ終了時などに保存し、異常終了でも直前まで残るようにする
- 「新しいページ」は今のページを保存して白紙にする(全消去で書いた物が消える事故を防ぐ)

### 文書
- README は利用者向け(起動・操作・設定)に絞る。ビルド・検証・環境などの開発者向け情報は別文書(例: docs/DEVELOPMENT.md)に分ける

## 段階
- v1(最初の完成形): 上記すべて。保存したメモを開き直す機能は無くてよいが、保存形式は開き直せる前提で設計する
- v2: iPhone のメモ帳程度のページ機能と、ペンの道具(下記「v2 要件」)
- v3 以降(候補): 選択・移動、ピンチでの拡大縮小・表示位置の移動、手書き数式→LaTeX 変換

## v2 要件

### ねらい
VR 上で手軽にメモでき、後で簡単に確認できること。大規模なメモは求めないが、
謎解きのメモなどでは広い面積が要る。ワールド内のスキップ番号など、長く残して何度も見返すメモがある。

### ペンの道具
- 色: 数色(例: 黒・赤・青・緑)。太さ: 3段階(例: 細・中・太)
- 消しゴム: ペンと同じく掴んで持つ物。ペンの近く(前後左右のどこか)に置く。トリガーを押しながらなぞると消える
  - 「線ごと消す」と「なぞった部分だけ消す」の両方。切替は道具パレットで
  - 消しゴムの操作も UNDO で戻せる
- 道具パレットと操作ボタンは紙の上の外側に2段で置く。「ボタンの上で新しくトリガーを押す」操作で選ぶ。紙は上端まで筆記可能とし、紙上の状態行は表示しない。失敗・復帰の案内は帯の上へ出す
- 色・太さは線ごとに保存し、後から道具を変えても過去の線は変わらない

### ページ
- 保存済みのページを一覧(縮小画像)から選んで開き直し、書き足し・消去ができる。自動保存は v1 と同じ
- 前後のページ送り
- 一覧の縮小画像: ページ全体の書いた範囲を切り出し、位置関係と縦横比を保って表示する(文字認識はしない)。見出し専用の帯・欄は設けない
- ★(ピン留め): 長く使うメモを一覧の先頭に固定する
- 通常の一覧からの削除は、ゴミ箱フォルダへ移すだけ。ゴミ箱から復元できる
- 2026-10-21 決定: ゴミ箱の中のページだけは、件数と元に戻せないことを確認してから完全削除できる。ADR 0004 の保持方針に対する明示的な例外とする。対象ページのJSON・PNG・関連バックアップだけを消し、保存形式や他ページは変更しない。失敗時は残った対象を示す
- 2026-10-23 決定: 設定した日数を経過したゴミ箱のページは、起動時と起動中に自動で完全削除する。しない／1日／14日／30日／60日、既定30日。起点は移した時刻で、以前のゴミ箱は更新後の初起動から数える。[PC設定と保存先の判断](adr/0006-desktop-settings.md)を参照
- 一覧の各ページには、縮小画像に加えて **ページの作成日時(日付と時刻)** を必ず表示する。
  並びは日付順。探す手がかりは書いた範囲の縮小画像と作成日時
- ワールド名は記録しない(2026-10-20 決定: VRChat に依存しない「VR 上で使えるメモ帳」にする)。
  旧保存形式のワールド名欄は読み込み時に無視する

### デスクトップ画面(2026-10-20 決定)
- 同じアプリに PC のウィンドウを足し、保存済みページの一覧・閲覧・書き足し・消去ができる
- マウスとペンタブレットで書ける。道具(色・太さ・消しゴム2種・UNDO・新しいページ)は VR と同じものを使う
- SteamVR を起動していなくても使える。SteamVR があるときは VR 側と同時に使える
- VR とデスクトップで書いた内容が食い違ったり、片方の編集で他方の編集が消えたりしない
- ページ一覧はまずデスクトップ画面に作り、VR 側の一覧は後で同じ仕組みを使って作る
- 「一覧」「ゴミ箱」は選択状態の分かるタブで切り替える。キーボードからも切り替えられる
- ゴミ箱はCtrl+クリック・Shift+クリック・Ctrl+Aで複数選択できる。右クリックは選択中の行なら全選択分、選択外ならその1件に作用する。「開く(閲覧)」は1件の時だけ表示し、復元・完全削除は複数件に対応する
- 手動の完全削除は右クリックまたはDeleteキーから確認画面を開き、「削除」を選んだ時だけ実行する。既定はキャンセル。「ゴミ箱」タブの右クリックから、全件の確認付きで空にできる。空の時は実行不可
- 右上の歯車（設定）から自動削除・SteamVR自動起動・VRの利き手／明るさ／ノートの出し方・保存先を変更でき、即時に保存する。保存先だけは移す／移さない／キャンセルを確認する。移す時は各コピーの内容を照合し、設定保存後に、元の内容とコピー先のサイズの確認が取れたファイルから元を削除する。残った元ファイルは対象を表示する。PCとVRは同じ保存先と設定を使う
- 設定ファイルの未知のキーは読み込み時に無視する。旧 `GestureMode` の値は読み込み時に現行値へ変換し、保存時は `WristButton` または `Disabled` を書く。
- SteamVRが停止中でも、自動起動のオン・オフを予約・変更・取り消しできる。HnMemoとSteamVRがともに起動し、SteamVRのアプリ登録に接続できたときに反映する。反映後はSteamVR側の登録値を表示する。
- 設定のドロップダウンは、クリックやキー操作で選んだ時だけ値を変える。閉じた状態ではマウスホイールで値を変えず、画面をスクロールする。開いている一覧の強調を、定期的な表示の更新で戻さない
- 既存のお絵かきソフトの形式への変換はしない(往復でずれが出るため)

### ノートの大きさ(2026-10-20 決定: 引き伸ばす方式)
- ノートを掴んで引っ張ると、書ける面積が広がる/狭まる(例: 角を掴んで引く。両手で持って広げる)。
  ノートの移動・持ち替えも今まで通りでき、掴む前にどちらになるか分かる
- ペンまたは消しゴムを持ったまま、先端が外側の拡大つまみの範囲にある時に新しくトリガーを押しても広げられる。押したまま動かし、離すと確定。紙で押し始めた入力は途中で拡大へ切り替えない。空いた手でグリップを使う方法も残す
- 線は実寸のまま(拡大縮小しない)。ボタン・パレットはノートの大きさによらず同じ実寸
- ページごとに大きさを保存し、開き直すとその大きさで出る。デスクトップ画面でもページ全体が見える
- PNG はページ全体を出す(書いた範囲だけの切り抜きは、必要が分かってから)
- 比較した案: 下へ伸びるページ(VR で全体を見渡せず謎解きに不向き)、大きさボタン(段階だけになる)

## やらないこと(v2)
- LaTeX 変換・文字認識、文字の打ち込み、フォルダ分け、検索、VRChat への送信・OSC 連携、Windows 以外

## 決定済みの事項と参照先
