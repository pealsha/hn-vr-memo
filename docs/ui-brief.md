# UI の用途と主な作業(UI 改善の基準)

UI を修正・点検するときの基準（2026-10-20 整理）。

## 利用者と場面
- 主な利用者は VRChat の QvPen・ピックアップ操作に慣れた日本語話者（PCVR ユーザー）
- **VR**: VRChat をしながら(PCVR、Virtual Desktop → SteamVR)。片手または両手にコントローラー。
  ノートは頭の約45cm先・48×36cm(最大80×60cm)。会話や移動の合間に数秒で使いたい
- **デスクトップ**: PC の前で、後から見返す・清書する・整理する。マウスまたはペンタブ。SteamVR を起動していないこともある

## 目的
VR の中で思いついたこと(数式・単語・謎解きの手がかり・スキップ番号など)を数秒で手書きで残し、
後から PC でも VR でも簡単に見つけて見返し、書き足せること。操作の基本は VRChat のピックアップ・QvPen と同じ感覚。

## 主な作業(重要な順)
### VR
1. **すぐ書く**: ノートを出す(反対の手のタップ位置を見て2回／1回タップ・SteamVRの割り当て等)→ペンを掴む→書く→閉じる。数秒で終わること
2. **書き損じを直す**: UNDO、消しゴム(線ごと/部分)
3. **色・太さを変える**
4. **過去のメモを探して見る・書き足す**: 一覧 → 書いた範囲の縮小画像・日時で探す → 開く → 書き足す → 戻る
5. **広げる**: 面積が足りない時にノートを広げて書き続ける
6. **よく使うメモを固定する**: ★
7. **困った時に戻す**: ノートを見失った(RECENTER)、保存に失敗した、追跡が切れた
8. **手首の判定位置を合わせる**: PC設定／VRダッシュボードから開始→ダッシュボードを閉じる→3秒準備→叩きたい所に指先を置いて約2秒静止→保存の合図。動いたら再試行し、中止・保存失敗・追跡切れから戻れること
### デスクトップ
1. **探して見る**: 一覧から書いた範囲の縮小画像・日時で目当てのページを見つけて開く
2. **書き足す・清書する**: マウス・ペンタブで、VR と同じ道具
3. **整理する**: ★、一覧／ゴミ箱タブの切り替え、ゴミ箱へ移す、ゴミ箱から複数件を戻す。不要なページはゴミ箱から確認付きで完全削除する。ゴミ箱タブの右クリックから全件を確認して空にする
4. **VR と同時に使う**: 同じページを両方で開いても食い違わない

## 合格の目安
- 主な作業を、README を読まずに画面だけで見つけられる。押す前に結果が予想でき、押した後の状態が分かる
- 誤操作しにくく、筆跡の変更は履歴から、通常の削除はゴミ箱から戻せる。ゴミ箱からの手動の完全削除は元に戻せないため、件数と結果を確認し、キャンセルを既定にする。設定した期限で行う自動削除は、設定画面で期限と元に戻せないことを示し、ゴミ箱のページに残り日数を出す
- VR の文字・ボタンは頭の約45cm先で読めて、ペン先で狙って押せる大きさ
- 慣れた後は少ない操作で済む(よく使う操作ほど近く・大きく)
- 必要な機能を省いたり隠したりすることを改善とみなさない
- エクスプローラーやメモアプリの慣例で分かる操作・目に見える結果は、常時の説明や成功通知を重ねない。エラーと復旧、完全削除の確認、独自の操作案内、ツールチップは残す

## 参考にする構成例
- VR: QvPen(VRChat)、Open Brush のパネル、SteamVR ダッシュボード、Meta Quest のパネルの文字サイズ指針
- デスクトップ: iPad / iPhone のメモ、Goodnotes、OneNote のページ一覧と描画画面
