# ADR 0005: 保存形式 v2 — 実寸座標・線ごとの色と太さ・ページ情報

## 決定
- v2 の保存形式を1回の変更でまとめて決める(formatVersion 2)。v2 で必要になる情報を先に全部入れる
- 線の位置は「板に対する割合(u, v)」ではなく、ページ上の実寸(メートル)で持つ。板の大きさに依存しない
- 線ごとに色と太さを持つ。太さは段階名ではなく実際の値で持つ(後で段階の定義を変えても過去の線が変わらない)
- ページごとに次を持つ: ★(ピン留め)、書いた時にいたワールド名の一覧(複数可・不明あり)
- v1(formatVersion 1)の JSON は読み込み時に v2 へ変換する。元の v1 ファイルは変換前に残す(上書きで失わない)
- JSON が正本、PNG は派生物(ADR 0002)は変えない

## 理由
- 板の引き伸ばし(v2 後半)をすると、割合の座標では線が伸び縮みしてしまう。実寸なら板の大きさと無関係
- 色・太さ・ピン・ワールド名を別々のタスクで順に足すと、形式変更と移行処理が何度も起きて過去のメモを壊す危険が増える
- ワールド名はページを跨ぐ書き足しがあるため単一値にしない

## 却下した案
- ワールドごとにページを固定・分類する: ワールドを跨いで書きたい場面がある(本人)
- 形式変更を機能ごとに分ける: 上記の移行リスク
- PNG をやめて専用ビューアで見る: 「後で簡単に確認」が損なわれる

## 改訂(2026-10-20)
- ワールド名の記録は取りやめ(本人判断)。保存形式のワールド名の欄は外す。既に [null] を書いた v2 ファイルは、読み込み時にその欄を無視する

## 影響
- 手書き見出しは保存形式に専用の項目を持たず、ページ上部の帯にある線から一覧表示時に作る想定
- ゴミ箱はファイルの移動で表す(形式には持たない)
