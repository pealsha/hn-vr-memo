# ADR 0004: 保存は自動、「全消去」ではなく「新しいページ」

## 決定
- 手動の保存ボタンは置かず、自動保存する(閉じる・新しいページ・終了時など。異常終了でも直前まで残す)
- 全消去ボタンの代わりに「新しいページ」: 今のページを保存してから白紙にする

## 理由
目的は「メモを取る手間をなくす」こと。保存し忘れて消える、全消去で誤って消える、はこの目的に対する最悪の失敗。
VR 内でボタンを押す手間を減らす意味でも、保存は利用者が意識しない方が良い。

## 却下した案
- 手動保存ボタン: 押し忘れで消える
- 全消去: 誤操作で消える(Task 001 でも危険性を指摘済み)
