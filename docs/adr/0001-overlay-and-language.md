# ADR 0001: SteamVR オーバーレイ + C#

## 決定
VRChat とは別プロセスの SteamVR オーバーレイアプリとして作り、言語は C# (.NET) とする。

## 理由
- VRChat 内(ワールド/アバターギミック)からは PC にファイルを保存できない
- 利用環境が SteamVR 経由なので OpenVR オーバーレイが使える
- C# は OpenVR 公式バインディングがあり、Windows 向け配布も容易

## 却下した案
- Python: 配布(exe化)が面倒、描画まわりの選択肢が弱い
- C++: 保守コストが高い
- Unity 製オーバーレイ: 重く、メモ帳には過剰
