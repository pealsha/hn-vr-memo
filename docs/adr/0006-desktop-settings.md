# ADR 0006: PC設定、ゴミ箱の期限、保存先の切替

## 決定

- 設定は標準WinForms部品と既存のUiThemeで作り、選択した時に既存AppOptionsへ保存する。失敗した値は表示にも反映しない。利き手・明るさは既存の変更処理をPCからも呼ぶ。
- ゴミ箱は既存の隔離フォルダに `.trashed-at` を追加し、JSONの `trashedUtc` にUTCの投入時刻を記録する。メモ本体のv1/v2形式は変えない。旧ゴミ箱へは機能導入後の初起動時刻を記録する。無効時も起点は記録する。
- 期限は投入時刻から正確に24時間×日数。残り日数は端数切上げで、期限後は0日。起動時と起動中の1分ごとに確認し、既存のPageCatalog.DeletePermanentlyで消す。失敗時はログに対象を残して次回再試行する。手動削除時の確認に対して、本人が選んだ自動削除は確認なしで期限を適用する例外。
- 自動起動は既存のAutoStartを共用する。VR接続中は既存の接続で操作し、Utility接続を開始・終了してVRを切断しない。状態を読めない時は「未確認」とし、オン／オフを推測しない。
- 保存先の「移す」は先に筆記を保存し、通常ページの関連ファイルとゴミ箱をコピーし、SHA-256（内容から求める照合値）を全件確認して設定を保存する。それから共有MemoSessionの保存先を交換し、元を削除する。コピーや設定保存の失敗では元を一切削除しない。元の削除だけの失敗では新しい保存先を使い、残った元ファイルを表示する。
- 移動先の異なるページは合わせて表示する。同一ID・同名ファイルは、どちらが新しいかを推測せず移動を止める。同一・親子フォルダやリンク経由の変更は止める。「移さない」は元の全メモを残し、新しい保存先の白紙へPCとVRを一緒に切り替える。
- Enable/Disableのcmdは画面を使えない時の登録・解除用に残す。app key、manifest、mutex・イベント名と既存設定項目名は変更しない。

## 理由と採らなかった案

メモの更新時刻は編集によって変わるため、ゴミ箱投入の起点には使わない。ゴミ箱だけの情報をメモ本体へ足す案は、読み書きや移行の範囲を広げるため採らない。sidecar（本体と並べる補助ファイル）なら旧メモをそのまま読み、復元時は取り除ける。

保存先を単に設定だけ書き換えると、開いているページの次の保存先と一覧が食い違う。全コピーを確かめてから同じセッションの保存先を交換する。衝突時の自動上書き・同一IDの複製は、編集の正本や履歴の判断を増やすため行わない。未知のファイルや空の元フォルダは残し、フォルダ全体の再帰削除は行わない。

Windows App SDKや新しいUIライブラリは導入せず、標準ComboBox・CheckBoxのキーボード操作とアクセシビリティを保つ。トグルの描画だけを既存の外観へ合わせる。

参考資料と操作・画像の検証結果はに残す。
