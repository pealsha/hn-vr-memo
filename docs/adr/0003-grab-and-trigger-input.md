# ADR 0003: 入力は「グリップで持ち、トリガーで投影筆記」

## 決定
- ペンと板はグリップで掴む物(左右どちらの手でも)。掴んだ時の位置関係を保つ(持ち方は自由)
- ペンを持った手のトリガーを押している間、ペン先を板へ垂直投影した位置に描く。有効距離は板の手前15cm(設定可)
- 接触方式(トリガー不要)は本実装では採らない

## 理由
- 実機比較でトリガー方式を採用した。VRChat の QvPen・ピックアップと同じ操作で覚えることがない
- 15cm は実機で「ちょうどよい」
- グリップ・トリガーは VRChat にも届くが、実機で特に実害はなかった
- 持ち方のスナップは不要: ペンが見えるので、どう持っても先端が分かる

## 却下した案
- 接触方式: 手応えがなく、板にぴったり当て続ける負担がある。比較で選ばれなかった
- 決まった持ち方へのスナップ: 自由な持ち方を優先した

## 影響
- グリップを表示切替に使えない(掴みと衝突)。板の出し入れは別の手段が要る
